# Roadmap: closing `branchCycleDescentData_nonempty`

*The last mathematical gap of the rigidity method (besides the RET covers axiom).*

## 0. Where we are

The rigidity criterion is fully assembled **except** one `sorry`:

```
branchCycleDescentData_nonempty
    (cert : RigidityCertificate G) (cover : IsGeometricGaloisCover G) :
    Nonempty (BranchCycleDescentData G cert)
```

Everything *downstream* of it is proven, axiom-free:

* `ArithmeticDescentData.ofBranchCycle` derives the pre-digested descent datum (its `inner`
  and `surjφ` are **theorems** via `sphereHom_inner_equiv_of_rigid` / `sphereHom_surjective_iff`);
* `branch_cycle_descent` runs the centerless extension lemma `extend_surjective_of_inner`;
* `RigidityCertificate.isRegularInverseGalois` composes RET + descent.

So the entire remaining mathematical content of the rigidity method is: **from a geometric Galois
cover `L/ℚ̄(T)` with group `G` and a rigidity certificate, produce the branch-cycle descent datum**
— the arithmetic fundamental-group tower, the geometric presentation, the Galois-twist data, and the
field translation back to a regular `ℚ(T)`-extension.

This file lays out how to build it, split into four modules that can be attacked independently once
the shared interface (`GeomTower`, `BranchTwist`) is frozen.

## 1. The mathematics (Fried–Völklein branch-cycle descent)

Write `Γ = Gal(ℚ̄/ℚ)`, `k(T) = ℚ(T)`, `k̄(T) = ℚ̄(T)`. Start from the geometric cover `L/k̄(T)`
with `Gal(L/k̄(T)) ≃* G` (this is the `cover` hypothesis, produced by RET over `ℚ̄`).

1. **Descend the base field of the tower (Module A).** `L` is finitely generated over `k̄(T)`;
   it is defined over a number field, and we may form a compositum `Ω` that is Galois over `k(T)`
   and contains `L`. This gives the *fundamental exact sequence*

   ```
   1 → N → E → Γ → 1,     N = Gal(Ω/k̄(T)),   E = Gal(Ω/k(T)),
   ```

   where the quotient `E/N ≃ Gal(k̄(T)/k(T)) ≃ Γ` is the arithmetic-vs-geometric splitting. The
   last isomorphism `Gal(k̄(T)/k(T)) ≃ Gal(k̄/k)` is the **regularity of `k(T)/k`** (equivalently:
   `k̄` and `k(T)` are linearly disjoint over `k`, and `k̄(T) = k̄ ⊗_k k(T)`). The geometric
   monodromy is `φ : N ↠ G` (restriction of `N`-automorphisms to `L`, transported by
   `Gal(L/k̄(T)) ≃ G`).

2. **Present the geometric group (Module B).** The geometric fundamental group of `ℙ¹ ∖ {r points}`
   over `k̄` is topologically generated by the `r` branch cycles subject to the single product-one
   relation: there is a surjection `pres : SphereGroup r ↠ N` (algebraic `π₁`), and `φ ∘ pres` is
   the sphere hom `sphereHom base` of the certificate's rigid tuple `base ∈ rigidTuples C`. **This
   is the Riemann Existence Theorem** (same content as `riemann_existence_cover_ax`, in its
   profinite/`N`-level form) — the irreducible geometric core.

3. **Branch-cycle formula (Module C).** For `e ∈ E` lifting `σ ∈ Γ` with cyclotomic character
   `χ(σ) ∈ Ẑˣ`, conjugation by `e` carries each inertia/branch generator `xᵢ` to a conjugate of
   `x_{π(i)}^{χ(σ)}` (Fried's branch-cycle argument via tame inertia `≅ Ẑ(1)` at each branch point).
   Transported through `φ`, this says the **Galois twist** of the monodromy tuple `base` by `e` is
   again a tuple `twist e` lying in the classes `(C₁^{χ(σ)}, …)`. **Rationality** (`cert.rational`)
   makes those classes equal to `(C₁,…,C_r)`, so `twist e ∈ rigidTuples C`, and `φ ∘ conj e` is
   `sphereHom (twist e)`. (The class-invariance *given* the cyclotomic action is elementary and is
   exactly `cert.rational`; the tame-inertia input is the irreducible part.)

   *This is the piece that supplies the hypothesis `sphereHom_inner_equiv_of_rigid` consumes: once
   `twist e ∈ rigidTuples C`, rigidity forces it simultaneously conjugate to `base`, so the twist is
   inner — the already-proven group theory takes over.*

4. **Field translation (Module D).** Given the arithmetic monodromy `ψ : E ↠ G` extending `φ`
   (produced downstream by the centerless extension lemma), the fixed field `L' = Ω^{ker ψ}` is a
   Galois extension of `k(T)` with `Gal(L'/k(T)) ≃ G`. Because `ψ|_N = φ` is **surjective**, `N`
   surjects onto `G`, i.e. `ker ψ ∩ N` has index `|G|` in `N`; equivalently `L' ∩ k̄(T) = k(T)`,
   which is exactly **regularity**: `k` is relatively algebraically closed in `L'`
   (`algebraicClosure ℚ L' = ⊥`). That yields `IsRegularInverseGalois G`.

## 2. Depth-to-build (nothing is a permanent axiom)

**Governing directive:** *everything here gets proved sorry-free eventually — no permanent axioms,
no permanent sorries.* So the classification below is **depth-to-build**, not "genuine vs.
irreducible." Every module is on the to-build list; they differ only in how much theory must be
erected first.

| Module | Content | Depth |
|--------|---------|-------|
| **A** Tower | Galois theory of `Ω/k(T)`; exact sequence; `Gal(k̄(T)/k(T)) ≃ Γ` via regularity/linear disjointness | **Shallow–medium** — Mathlib-expressible field theory. The one non-elementary input is the `ℚ(T)`-model `Ω ⊇ L` (descent/finite-generation); isolate and build it. |
| **B** Presentation | `SphereGroup r ↠ N`, `φ∘pres = sphereHom base` | **Deep** — RET at the `N` (profinite geometric `π₁`) level; the algebraic Grothendieck–GAGA content behind `riemann_existence_cover_ax`. The deepest tower; build the étale/topological `π₁` comparison for `ℙ¹ ∖ S` over `ℚ̄`. Attack last, but it *is* to be built. |
| **C** Branch cycle | `twist`, `twist_mem`, `φ_conj_pres` | **Medium–deep** — the rationality→class-invariance glue is shallow (it is the `IsRationalClass` content); the tame-inertia + cyclotomic-character input (`Γ` acts on tame inertia `≅ Ẑ(1)` through `χ`) is the deep part — build ramification theory of `ℚ̄(T)/ℚ̄` at the branch points and Fried's branch-cycle argument. |
| **D** Translation | `descentTranslation`: fixed field of `ker ψ` is regular | **Shallow–medium** — fixed-field Galois theory + a regularity computation (constant field `= k` ⇔ `ψ|_N` surjective). No deep external input; needs the tower's field realization. |

Payoff of the decomposition: the shallow glue (A's exact sequence, C's rationality argument, D's
regularity computation) gets *proven* immediately, and the deep residue is isolated into recognizable,
individually-citable towers (the `ℚ(T)`-model existence; the tame branch-cycle formula; the geometric
`π₁` comparison) — each of which is then itself decomposed and built, never left as an axiom.

**Interface consequence (important):** to prove A and D sorry-free, `GeomTower` must be **enriched to
carry the field realization** (the field `Ω`, its `Algebra` maps over `k(T)` and `k̄(T)`, the
`IsGalois` witnesses, and the identifications `E ≃ Gal(Ω/k(T))`, `N ≃ Gal(Ω/k̄(T))`). You cannot
produce the regular field `L'` (D) or construct the tower (A) from abstract groups alone. Enriching
`GeomTower` is therefore the *first* concrete step, and it re-freezes the interface for the C/D
producers. This is done in `Descent.Data` / `Descent.Tower`.

```
Rigidity/RET/Descent/Data.lean            -- FROZEN INTERFACE (no sorry):

                                          --   ofBranchCycle, GeomTower, BranchTwist
Rigidity/RET/Descent/Tower.lean           -- Module A+B: geomTower_nonempty (sorry) + targets
Rigidity/RET/Descent/BranchCycle.lean     -- Module C:   branchCycleTwist   (sorry) + targets
Rigidity/RET/Descent/FieldTranslation.lean-- Module D:   descentTranslation (sorry) + targets
Rigidity/RET/Descent.lean                 -- assembly (no sorry of its own):
                                          --   branchCycleDescentData_nonempty
                                          --     := geomTower_nonempty ▸ branchCycleTwist ▸ descentTranslation
                                          --   + arithmeticDescentData_nonempty, branch_cycle_descent,
                                          --     RigidityCertificate.isRegularInverseGalois
```

`GeomTower G cert` is the shared carrier (the geometric side of the descent datum): `E, N, φ, pres,
surjPres, base, base_mem, φ_pres`. `BranchTwist tw` is Module C's output (`twist, twist_mem,
φ_conj_pres`). The assembly glues `GeomTower` (A+B) + `BranchTwist` (C) + `descentTranslation` (D)
into `BranchCycleDescentData`.

**Interface freeze rule for parallel work:** subagents may fill `sorry` bodies and add *private*
helper lemmas in their own module file, but must NOT change the public signatures in `Data.lean`
or the producer signatures (`geomTower_nonempty`, `branchCycleTwist`, `descentTranslation`). This
keeps the four modules independently buildable.

interface is frozen (step 1 of the enrichment). Step 5 is its own project.
